### Step 1: Initial Setup (5 minutes)
```bash
# Run automated setup
./setup.ps1  # Windows
# or
./setup.sh   # Mac/Linux

# Install dependencies
npm install
```

### Step 2: Configure (2 minutes)
```bash
# Update .env file
# Set app paths and device names
```

### Step 3: Run Tests (1 minute)
